# SOMNGUARD

## Definición de hecho

**Estado:** En progreso
**Fecha:** 2026-06-19

</div>

</div>
Este documento define los criterios mínimos que debe cumplir un documento para considerarse completo, revisado y listo para su uso, garantizando consistencia, calidad, claridad y trazabilidad en la documentación del proyecto.

---

Un documento está **done** cuando:

- [ ] Está enlazado desde el `README.md` de su sección
- [ ] El estado cambió a **Estable**
- [ ] Los enlaces relativos funcionan
- [ ] No contiene información sensible
- [ ] El CHANGELOG fue actualizado si el cambio modifica gobernanza, estructura de carpetas, o un contrato compartido (API, modelo de datos, convenciones de Git)
