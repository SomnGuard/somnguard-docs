# Registro de decisiones de arquitectura (ADRs)

Las ADRs viven en esta carpeta (`records/`). El **registro central** (tabla con estado y fecha de cada ADR) y el proceso para crear una ADR están en [`../README.md`](../README.md).

Nuevas ADRs se agregan como `ADR-NNN-descripcion-corta.md` siguiendo la plantilla [`_template-adr.md`](../_template-adr.md) y se registran en [`../README.md`](../README.md).
