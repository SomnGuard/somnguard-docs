## Contenido

| Ruta | Descripción |

| [diagram-index.md](./diagram-index.md) | Índice de todos los diagramas (fuente + exportación) |

Reglas:

- Todo diagrama debe tener fuente editable en `diagrams/source/` y su exportación en `diagrams/exports/`.
- Registrar cada diagrama en `diagram-index.md`.
- Los diagramas se crean en Mermaid con convenciones UML (ver `../00-documentation-governance/documentation-rules.md`).
